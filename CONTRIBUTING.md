# Contributing

Changes should preserve the scope and presentation quality of the exhibition version. Start with the setup and validation commands in [Development](docs/development.md), then describe the visitor-facing change and the checks you ran in your pull request.

Do not add private source files, electronics-lab simulation, workshop materials, source model files, or unlicensed third-party assets. Preserve applicable third-party notices. The repository does not grant a license to reuse the original application, 3D model, photographs, or other project artwork.
